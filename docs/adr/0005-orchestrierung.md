# AutomationOS-Orchestrierung: modularer JobRunner, State-Split, Wellen mit Scrub-first

AutomationOS läuft als alleiniger Host im eigenen Obsidian-Plugin (`iserv-integration`) mit Modulen: `IServClient` (Transport injizierbar), **modularer JobRunner** (Modul-Registry: Core/Stundenplan+Vertretung 15 min, Mails 15 min, Aufgaben 30 min, Dateien 60 min — alles Settings; Session = Auto-Login on startup + stilles Re-Login bei Expiry; geteilter Rate-Limiter ~max 2 req/s; manueller Trigger pro Modul für gezielten Schnellsync), `StateStore` (`queue.json`, `emails.json` TTL 48h, `data.json` non-cred; **Arbeiten = Vault-Frontmatter-Notizen**, 4-Status), `Keychain` (safeStorage, Creds+Session-Cookie), `Views` (T7). Release-Wellen: **Welle 0 = Inzidenz-Scrub strikt vor allen weiteren Commits** (History filter-repo/BFG + force-push; nextDue.js-CONFIG raus) → **T11 Aufgaben-Spike** (dokumentiert, warum `tasks/` `[]` liefert) → **Welle 1 MVP** (safeStorage-Login, JobRunner, HA-Kern mit Aufgaben, Review-Queue, zwei ItemViews, Notices) → **Welle 2 Polish** (PDFium-Vollviewer, Desktop-Fallbacks) → **Welle 3 Arbeiten+Vorbereitung** (nach T10: Arbeit-Notizen, Countdown, Vorbereitungsfenster, Noten-Gewichtung). Testbarkeit: Transport-Seam + Read-Only-Guard-Test (nach Login nur GET; POST nur Login+Telemetrie); Node-Test-Runner, keine Build-Pipeline.

**Status:** accepted

**Considered options:** (i) Monolith-Sync-Job (Request-Burst auf einmal, kein gezielter Schnellsync — nein) vs. (ii) N unabhängige Job-Prozesse (Zersplitterung) — gewählt: **ein JobRunner mit Modul-Registry** ((ii)-Semantik, (i)-Einfachheit). Templater/Custom-Frame als Host — abgelehnt (T6/T7). Aufgaben-Spike im Build (a) vs. davor als eigenes Ticket (b) — gewählt (b): sauber dokumentiert, warum `tasks/` `[]` ist, bevor der Build drauf baut.

**Consequences:** Welle 0 ist destruktiv (force-push → Owner-Bestätigung nötig); T11 muss vor Welle 1 resolved sein (Aufgaben-Sektion im MVP gated); `docs/iserv-api.md`-Update aus T11 erst nach dem Scrub (keine Commits davor); Welle 3 hängt an T10.
